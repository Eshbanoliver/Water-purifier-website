# Water Purifier Dealer Website

A high-performance, modern, and responsive multi-page website template designed for Water Purifier dealers and service providers. This project features a premium UI with smooth animations, interactive components, and a clean professional aesthetic.

## 🚀 Features

- **Responsive Design**: Fully optimized for desktops, tablets, and mobile devices.
- **Service & Product Showcase**: Detailed sections for various water purifier models with high-quality imagery and feature lists.
- **Interactive UI Components**:
  - Glassmorphism effects in recruitment/why-choose-us sections.
  - Animated stat counters.
  - Scroll-triggered animations for a dynamic feel.
  - Interactive FAQ accordion.
  - Infinite scroll testimonial slider.
- **Service Management**: Dedicated sections for Installation, AMC (Annual Maintenance Contract), and Repair services.
- **Contact & Leads**: Integrated contact forms and clear Call-to-Action (CTA) buttons throughout the site.
- **SEO Optimized**: Semantic HTML5 structure with proper meta tags, `robots.txt`, and `sitemap.xml` for maximum search engine visibility.
- **Location Integration**: Embedded Google Maps for physical store location.

## 🛠️ Technologies Used

- **HTML5**: Semantic structure.
- **CSS3**: Custom styling with CSS Variables, Flexbox, Grid, and Keyframe animations.
- **JavaScript (Vanilla)**: For interactive elements, scroll animations, and mobile menu functionality.
- **Font Awesome**: Professional iconography.
- **Google Fonts**: Modern typography (Poppins).

## 📂 Directory Structure

```text
├── assets/             # Optimized images and brand assets
├── index.html          # Homepage
├── about.html          # About Us page
├── services.html       # Products & Services page
├── faq.html            # Frequently Asked Questions
├── contact.html        # Contact Us page
├── style.css           # Global stylesheets and design system
├── robots.txt          # Search engine instructions
├── sitemap.xml         # Search engine index of all pages
└── script.js           # Core website logic and animations
```

## ⚙️ Setup Instructions

1. **Clone the repository**:
   ```bash
   git clone <repository-url>
   ```
2. **Open the project**:
   Simply open `index.html` in any modern web browser to view the site locally.
3. **Customization**:
   - Update the logo in `assets/logo.png`.
   - Modify contact details in the top bar and footer sections across all HTML files.
   - Adjust the Google Maps embed link in `contact.html` and the footer.
